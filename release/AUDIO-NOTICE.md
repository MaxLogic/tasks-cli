# Bundled spoken announcements

The fixed announcement clips were generated with elevenlabs.io using the
premade "Bella - Professional, Bright, Warm" voice and
`eleven_multilingual_v2`. No voice model or API credential is distributed.
Generation settings, timestamps and hashes are recorded in
`viewer/assets/announcements/manifest.json` in the source repository and in
the viewer's bundled assets.

The project owner confirmed on 2026-10-06 that these clips were generated
during a paid subscription, which includes commercial use of generated audio.
See https://help.elevenlabs.io/hc/en-us/articles/13313564601361-Can-I-publish-the-content-I-generate-on-the-platform.

The repository's MIT license covers its source code. Generated audio remains
subject to the generation account's rights and ElevenLabs' applicable terms:
https://elevenlabs.io/terms-of-use-eu.
